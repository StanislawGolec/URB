# QMIX with TorchRL and Clustered Routes (`qmix_torchrl_clusters`)

## Overview

`qmix_torchrl_clusters.py` implements the **QMIX** (Monotonic Value-Function Factorisation for Deep Multi-Agent Reinforcement Learning) algorithm using PyTorch RL (**TorchRL**) integrated with pre-computed **clustered routes** and action masks.

It is designed for fleet-level Connected Autonomous Vehicle (CAV) routing in mixed traffic environments, allowing agents to choose among representative route clusters generated per Origin-Destination (OD) pair.

---

## Technical Details

### Architecture
- **Individual Q-Networks:** Multi-agent MLP that maps per-agent observations (optionally enhanced with OD-pair embeddings or route congestion features) to individual action values $Q_i(s, a_i)$.
- **Mixing Network:** Feed-forward network with non-negative weights generated by hypernetworks conditioned on the global state $s$. It enforces the Individual-Global-Max (IGM) condition:
  $$\frac{\partial Q_{tot}}{\partial Q_i} \ge 0$$
- **Action Masking:** When clustered routes provide varying numbers of valid paths across OD pairs, `AVMaskWrapper` applies invalid action masking to prevent selection of non-existent routes.
- **Exploration:** $\epsilon$-greedy schedule with linear decay over the initial training fraction.
- **Loss Function:** `QMixerLoss` with TD(0) value estimators and target networks updated via Polyak averaging (`SoftUpdate`).

## Usage

Run an experiment via CLI:

```bash
python scripts/qmix_torchrl_clusters.py \
    --id qmix_clusters_alt10_ing2_s42 \
    --alg-conf config1 \
    --env-conf clusters_eta \
    --task-conf altruistic_10 \
    --net ingolstadt_custom2 \
    --env-seed 42 \
    --torch-seed 42
```

### Supported Configurations
- **Algorithm Configurations (`config/algo_config/qmix_torchrl_clusters/`):**
  - `config1.json`: Baseline QMIX setup (learning rate $4 \times 10^{-4}$, 200 iterations, 256 hidden cells, 192 mixing embed dim).
  - `config2.json`: Higher capacity (320 cells, 256 mixing dim, 400 iterations).
  - `config3.json`: Deeper policy network (depth 5, 500 iterations).
  - `config4.json`: Wide architecture (384 cells, 320 mixing dim, 800 iterations).
  - `config5.json`: Fast learning setup (1000 iterations, smaller batch size).
  - `test.json`: Minimal setup for smoke tests.

- **Environment Configurations (`config/env_config/`):**
  - `clusters_eta.json`: Enables `use_clustered_routes`, ETA observations, and candidate path sets.
  - `clusters_eta2.json`: Alternative cluster routing setup with refined smoothing.
